Cách Đưa Web Lên GitHub Pages

Ứng dụng đã được thiết kế 100% không cần backend riêng. Bạn chỉ cần đưa file index.html lên GitHub là có ngay website để hàng chục người cùng chơi!

1

Tạo một Repository mới trên GitHub

Truy cập github.com/new, đặt tên cho repository (ví dụ: quiz-game), chọn chế độ Public và nhấn Create repository.

2

Tải file index.html lên Repository

Nhấn "uploading an existing file" trên GitHub rồi kéo thả toàn bộ file index.html (và file README.md) từ máy tính của bạn vào, sau đó nhấn Commit changes.

3

Kích hoạt GitHub Pages (1 Click)

Vào tab Settings của repo → Chọn mục Pages ở cột bên trái → Tại phần Build and deployment, chọn Branch: main / root rồi nhấn Save.

Chờ 1-2 phút, website của bạn sẽ hoạt động tại địa chỉ: https://<ten-ban>.github.io/<ten-repo>/

Cơ Chế Đồng Bộ Nhiều Người Chơi Cùng Lúc Hoạt Động Thế Nào?

• Ứng dụng tích hợp công nghệ MQTT over Secure WebSocket (WSS) kết hợp BroadcastChannel.
• Chủ phòng gửi tín hiệu đồng hồ và câu hỏi qua kênh Cloud Relay trực tiếp.
• Mọi điện thoại và máy tính kết nối vào mã phòng đều tính toán thời gian từ timestamp đồng bộ nên đếm ngược 15s, 14s, 13s... chính xác đến từng mili-giây!
• Bảng xếp hạng và điểm số được máy Host cập nhật tập trung và phát tán đồng loạt cho toàn phòng sau mỗi câu, đảm bảo 100% khớp nhau.
• Không lo lộ đáp án trước vì Host chỉ gửi nội dung đáp án đúng sau khi hết giờ thi (Anti-cheat bảo mật tuyệt đối).
